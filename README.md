## About the Project
This is still WIP come back later.

This project is part of the course *Imaging for the Life Sciences (SS26)* at ZHAW.
ClimbingVault explores interactive computer vision methods for detecting 
and segmenting climbing holds in indoor climbing gym images.
The long-term goal is to enable semi-automated digitization of climbing routes from images.

## Dataset

This project uses a [dataset](https://www.kaggle.com/datasets/tomasslama/indoor-climbing-gym-hold-segmentation/data),
